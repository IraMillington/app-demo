# app-demo

An interactive demo of Ira's Health and Claro iPhone apps, running their real code on
invented data: https://iramillington.github.io/app-demo/

The site at the top of `main` is rebuilt automatically from the apps' sources; do not edit
it by hand. How it is built, and what is real and what is stood in: [tools/README.md](tools/README.md).
